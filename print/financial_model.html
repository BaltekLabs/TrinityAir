Preferred Base Case: The investor-facing base case is the Capital-Light Operator Access Model. Trinity Air Link controls the infrastructure, charging, dispatch, passenger-processing, and data layer while certified independent operators carry vehicle capex, pilots, fleet maintenance, insurance, and vehicle financing.

Capital Structure — Deployment Options

Capital-Light Operator Access Case: approximately $107M–$113M total investment, with a Hybrid Case of approximately $115M–$121M. The financial model retains the $129M owned-fleet case as an upside/control scenario, not the preferred launch baseline. The $32M Phase 3 vehicle deployment remains the full-control owned-fleet case.

Phase 3 Deployment Options

ModelPhase 3 Capital NeedDescription

Trinity Air Link monetizes pad access, bay use, passenger facility fees, charging/energy services, dispatch software, data services, and revenue share.

Owned Fleet Model$32MTrinity Air Link purchases or finances the initial eVTOL and AV fleet, capturing more revenue but assuming more asset, maintenance, insurance, and regulatory exposure.

Terminal Value / Exit Upside

Terminal value represents the estimated value of the stabilized Trinity Air Link platform at the end of the forecast period, typically calculated using an EBITDA exit multiple or stabilized infrastructure asset valuation. Terminal value is an exit/refinance/recapitalization assumption and is not counted as Year 5 operating cash flow.
