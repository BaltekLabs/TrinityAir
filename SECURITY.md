# Security policy

This is a public static website repository. Do not report ordinary public project claims as security issues.

Report exposed credentials, private data, or a website vulnerability to `partnerships@trinityairlink.com` with the subject `Trinity Air Link security report`.

Do not include sensitive proof in a public GitHub issue. This repository must not be used as a data room, and client-side password checks must not be added as a substitute for server-side authentication.
