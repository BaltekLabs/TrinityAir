# Trinity Air Link — Grant & Incentive Verification

**Verification date:** 2026-04-09  
**Purpose:** Confirm whether grants/incentives referenced in project materials are still active and describe how to message them accurately.

## Verified Program Status (Summary)

| Program / Incentive | Status (2026) | Messaging Guidance |
|---|---|---|
| USDOT **RAISE** grants (successor to TIGER/BUILD) | Active competitive program | Refer to RAISE, not TIGER as a current standalone program. |
| Federal Historic Tax Credit (20%) | Active (subject to eligibility/qualified rehab rules) | Keep as "potential" equity support, not guaranteed proceeds. |
| Texas Enterprise Fund (TEF) | Active state incentive mechanism | Keep as application-based/competitive and performance-driven. |
| New Markets Tax Credit (NMTC) | Active federal allocation program | Keep as potential financing source via allocation partners. |
| FAA eIPP | Active integration/coordination program | Do **not** position as a direct grant or co-investment source. |

## Key Corrections Applied
- Replaced legacy references to **TIGER grants** with **RAISE (successor to TIGER/BUILD)** in active print collateral.
- Removed phrasing that implied **eIPP = direct funding/co-investment**.
- Reframed FAA-related funding language as **competitive discretionary programs where eligible**.
